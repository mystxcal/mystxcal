Some of my work:

| Tool | What | Why |
|---|---|---|
| ⚡ [RIFT](https://github.com/mystxcal/rift) | Live transfer between two online machines | Nothing stored in between, every path raced |
| 📮 [SSS](https://github.com/mystxcal/sss) | Store-and-forward handoff between machines that are not online together | Short retrieval code, encrypted transport, automatic expiry |
| 💬 [Chatinabox](https://github.com/mystxcal/chatinabox) | Codex CLI sessions over Telegram | Leave the terminal, come back to the same session |
| 🪞 [Remote Browser](https://github.com/mystxcal/remote-browser) | Chromium on the server, mirrored to viewers | Scriptless, so the page's text stays text |
| 💎 [Flourite](https://github.com/mystxcal/flourite) | A frontier-scale harness for exact, difficult tasks | One evolving artifact, decision-changing work, verifiable evidence |
| 🗂️ [FilesToAI](https://github.com/mystxcal/filestoai) | A local project into clean, measured context for a language model | Select the right files, see the token cost, copy once |
| 📤 [FrankenFile](https://github.com/mystxcal/frankenfile) | Six characters and they get the files | Immutable, expiring, self-hosted |
| 📝 [Agentic Word Documents](https://github.com/mystxcal/agentic-word-documents-system) | Markdown, Excel and Word fragments into one `.docx` | Editable Word out, and a PDF proven page by page |
| 📄 [FrankenMarkdown](https://github.com/mystxcal/frankenmarkdown) (fork) | Markdown in, typeset PDF out | One binary. No browser, no LaTeX, no Node |
